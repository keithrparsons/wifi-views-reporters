Mac Wi-Fi Report

macOS has a built-in Wi-Fi diagnostic, wdutil, that prints everything about your connection in one dense block. Paste it here and get a clean report that explains what each number means and what stands out.

  1. Open TerminalApplications, then Utilities, then Terminal.
  2. Run this and press Return
    sudo wdutil info | pbcopy
    Type your Mac password when asked. Nothing shows as you type. The output goes straight to your clipboard.
  3. Paste it belowClick in the box and press Command-V.

Your paste never leaves this page. There is no upload: your browser builds the report. Hiding identifying details masks MAC addresses, the network name, IP addresses and Bluetooth device names, so the report is safe to send to someone helping you. macOS itself hides the network name and BSSID in wdutil's output, so those stay hidden either way.

Built by Keith Parsons · CWNE #3. wdutil is part of macOS; this page reads its text output and does not run anything on your Mac.
