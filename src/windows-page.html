Windows Wi-Fi Report

Windows has a built-in Wi-Fi command, netsh wlan, that prints your connection, your adapter and every network it can hear. Paste it here and get a clean report that explains what each number means and what stands out.

  1. Open TerminalRight-click the Start button and choose Terminal (on Windows 10, Windows PowerShell).
  2. Paste this and press Enter
    & { netsh wlan show interfaces; netsh wlan show drivers; netsh wlan show networks mode=bssid } | clip
    No administrator rights needed. The output goes straight to your clipboard.
  3. Paste it belowClick in the box and press Ctrl-V.

Your paste never leaves this page. There is no upload: your browser builds the report. Hiding identifying details masks MAC addresses, the adapter ID and every network name, so the report is safe to send to someone helping you.
