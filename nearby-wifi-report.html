Nearby Wi-Fi Report

lswifi, a free scanner by Josh Schmelzle, lists every Wi-Fi network your computer can hear on Windows, macOS and Linux. Paste its output here and get a clean report: who is on which channel, how strong, how secure, and what stands out.

  1. Install lswifiNeeds Python 3.13 or newer: python3 -m pip install lswifi. On a Mac, use the python.org Python and allow it in Location Services.
  2. Run this and press Return
    lswifi --json | pbcopy
    On Windows, use lswifi --json | clip. The plain table works too.
  3. Paste it belowClick in the box and press Command-V (Ctrl-V on Windows).

Your paste never leaves this page. There is no upload: your browser builds the report. Hiding identifying details replaces network names with numbers and masks the device part of each BSSID, so the report is safe to send to someone helping you.

Built by Keith Parsons · CWNE #3. lswifi is Josh Schmelzle's open-source scanner (BSD-3 license); this page reads its output and does not run anything on your computer.
